# 🕷️ Desarrollo de Aplicaciones Web Server Side Rendering
Proyecto de la materia desarrollar un Web Server Rendering

# 🚀 Competencias a desarrollar 
El participante identifica los frameworks más utilizados en la industria para el desarrollo de aplicaciones web de pila completa y emplea uno de ellos para desarrollar aplicaciones web siguiendo las mejores prácticas de desarrollo.

# 🖼️ Convecion de iconos para Commits 

| Icono | Tipo de commit | ¿Para qué se utiliza?                                    |
| ----- | -------------- | -------------------------------------------------------- |
| ✨     | `feat`         | Agregar una nueva función o característica.              |
| 🐛    | `fix`          | Corregir un error en el código.                          |
| 📚    | `docs`         | Agregar o modificar documentación.                       |
| 🎨    | `style`        | Cambiar estilos o formato sin afectar el funcionamiento. |
| ♻️    | `refactor`     | Reorganizar o mejorar el código sin cambiar su función.  |
| ✅     | `test`         | Agregar o modificar pruebas.                             |
| 🔧    | `chore`        | Realizar tareas de mantenimiento o configuración.        |
| ⚡     | `perf`         | Mejorar el rendimiento de la aplicación.                 |
| 📦    | `build`        | Modificar archivos o herramientas de compilación.        |
| 👷    | `ci`           | Cambiar la configuración de integración continua.        |
| ⏪     | `revert`       | Revertir o deshacer un commit anterior.                  |
| 🔒    | `security`     | Corregir o mejorar la seguridad del proyecto.            |
